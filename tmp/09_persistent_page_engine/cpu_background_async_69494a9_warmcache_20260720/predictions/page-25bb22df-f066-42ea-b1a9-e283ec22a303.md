## 下载历史行情数据

download_history_data(stock_code, period, start_time='', end_time='')

释义

补充历史行情数据

参数

stock code-string 合约代码

○ period - string 周期

○ start_time - string 起始时间

o end_time - string 结束时间

返回

○ 无

备注

同步执行，补充数据完成后返回

download_history_data2(stock_list, period, start_time='', end_time='', callback=None)

## 释义

## 参数

补充历史行情数据，批量版本

○ stock_list - list 合约列表

○ period - string 周期

○ start time - string 起始时间

o end_time - string 结束时间

callback - func 回调函数

参数为进度信息dict

total - 总下载个数

■ finished - 已完成个数

stockcode - 本地下载完成的合约代码

message - 本次信息
