Definition 4.1 (Divided Differences). The divided differences for a function \( f(x) \) are defined as follows:

\[
\begin{array}{l} f [ x _ {k} ] = f (x _ {k}), \\ f [ x _ {k - 1}, x _ {k} ] = \frac {f [ x _ {k} ]}{x _ {k}} \frac {f [ x _ {k - 1} ]}{x _ {k - 1}}, \\ f [ x _ {k - 2}, x _ {k - 1}, x _ {k} ] = \frac {f [ x _ {k - 1} , x _ {k} ] \quad f [ x _ {k - 2} , x _ {k - 1} ]}{x _ {k} \quad x _ {k - 2}}, \tag {13} \\ f [ x _ {k 3}, x _ {k 2}, x _ {k 1}, x _ {k} ] = \frac {f [ x _ {k 2} , x _ {k 1} , x _ {k} ]}{x _ {k}} \frac {f [ x _ {k 3} , x _ {k 2} , x _ {k 1} ]}{x _ {k 3}}. \\ \end{array}
\]

The recursive rule for constructing higher-order divided differences is

\[
f [ x _ {k \quad j}, x _ {k \quad j + 1}, \dots , x _ {k} ] = \frac {f [ x _ {k \quad j + 1} , \dots , x _ {k} ] \quad f [ x _ {k \quad j} , \dots , x _ {k \quad 1} ]}{x _ {k} \quad x _ {k \quad j}} \tag {14}
\]

and is used to construct the divided differences in Table 4.8.
