万能公式： \(\left\{ \begin{array}{l}\sin x = \frac{\sin x}{1} = \frac{2\sin\frac{x}{2}\cos\frac{x}{2}}{\sin^2\frac{x}{2} + \cos^2\frac{x}{2}} = \frac{2\tan\frac{x}{2}}{1 + \tan^2\frac{x}{2}}\\ \cos x = \frac{\cos x}{1} = \frac{\cos^2\frac{x}{2} - \sin^2\frac{x}{2}}{\cos^2\frac{x}{2} + \sin^2\frac{x}{2}} = \frac{1 - \tan^2\frac{x}{2}}{1 + \tan^2\frac{x}{2}}\\ \tan x = \frac{2\tan\frac{x}{2}}{1 - \tan^2\frac{x}{2}} \end{array} \right.\)
