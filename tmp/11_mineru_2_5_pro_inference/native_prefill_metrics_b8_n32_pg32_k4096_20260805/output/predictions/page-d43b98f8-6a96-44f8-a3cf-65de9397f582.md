2.3.17【柯西不等式法】

▲适用题型：

常用于根式中有和为定值时，比如求 \( f(x) = \sqrt{m(x + p)} + \sqrt{n(-x + q)} \) 最大值；

▲方法原理：

1. 二维柯西不等式:

设 \(a, b, c, d\) 均为实数，有 \((a^2 + b^2)(c^2 + d^2) \geq (ac + bd)^2\) 当且仅当 \(\frac{a}{c} = \frac{b}{d}\) 时等号成立；

向量法证明： \(\begin{cases} \vec{m} = (a,b),\vec{n} = (c,d),|\cos \theta |\leq 1 \\ \Rightarrow |\vec{m}\cdot \vec{n}| = \left\| \vec{m}\right\| \vec{n}\left|\cos \theta \right|\leq \left|\vec{m}\right\| \vec{n} \\ \Rightarrow |ac + bd|\leq \sqrt{a^2 + b^2}\sqrt{c^2 + d^2}\\ \Rightarrow (a^2 +b^2)(c^2 +d^2)\geq (ac + bd)^2 \end{cases}\) ；取等时向量共线，即 \(\frac{a}{c} = \frac{b}{d}\)

解答题用到柯西不等式，即可用此证明；

2. n 维柯西不等式:

\((a_{1}^{2} + a_{2}^{2} + a_{3}^{2} + \dots +a_{n}^{2})(b_{1}^{2} + b_{2}^{2} + b_{3}^{2} + \dots +b_{n}^{2})\geq (a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3} + \dots +a_{n}b_{n})^{2}\) 字母均为 \(\mathsf{R}\)

当且仅当 \(\frac{a_1}{b_1} = \frac{a_2}{b_2} = \frac{a_3}{b_3} = \dots = \frac{a_n}{b_n}\) 时等号成立，\(\mathsf{n}\) 维向量证明；

比如求 \( f(x) = \sqrt{m(x + p)} + \sqrt{n(-x + q)} \) 最大值：

\[
\Rightarrow \left\{ \begin{array}{l} {a = \sqrt {m}, b = \sqrt {n}, c = \sqrt {x + p}, d = \sqrt {- x + q}} \\ {\sqrt {m (x + p)} + \sqrt {n (- x + q)} \leq \sqrt {\left(\sqrt {m} ^ {2} + \sqrt {n} ^ {2}\right)} \sqrt {\left(\sqrt {x + p} ^ {2} + \sqrt {- x + q} ^ {2}\right)} = \sqrt {m + n} \sqrt {q + q}} \\ {\text {当且仅当} \frac {\sqrt {m}}{\sqrt {x + p}} = \frac {\sqrt {n}}{\sqrt {- x + q}} \text {时取等};} \end{array} \right.
\]
