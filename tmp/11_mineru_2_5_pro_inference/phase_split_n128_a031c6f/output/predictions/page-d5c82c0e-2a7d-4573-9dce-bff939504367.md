The following proposition describes the close relationship between the Nijenhuis operator and the Rota-Baxter operator. Similar results hold for Hom-associative conformal algebras (see prop 6.2 of [4]). Let us observe, if these results hold for Hom-Leibniz conformal algebras or not.

Proposition 2.10. Let \(\mathcal{N}_h:\mathcal{L}\to \mathcal{L}\) be a \(\mathbb{C}[\partial]\)-module homomorphism over a Hom-Leibniz conformal algebra \(\mathcal{L}\). Then

(1) \(\mathcal{N}_h\) is a Nijenhuis operator if and only if \(\mathcal{N}_h\) is a Rota-Baxter-operator of weight 0, given that \(\mathcal{N}_h^2 = 0\).

(2) \(\mathcal{N}_h\) is a Nijenhuis operator if and only if \(\mathcal{N}_h\) is a Rota-Baxter-operator of weight \(-1\), given that \(\mathcal{N}_h^2 = \mathcal{N}_h\).

(3) \(\mathcal{N}_h\) is a Nijenhuis operator if and only if \(\mathcal{N}_h\) is a modified RB-operator of weight \(\mp 1\), given that \(\mathcal{N}_h^2 = \pm Id\).

(4) \(\mathcal{N}_h\) is a Nijenhuis operator if and only if \(\mathcal{N}_h \pm Id\) is a RB-operator of weight \(\mp 2\), given that \(\mathcal{N}_h^2 = Id\).
